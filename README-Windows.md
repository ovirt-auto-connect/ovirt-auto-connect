# oVirt Auto Connect для Windows

Нативное приложение для Windows x64. Установка Python или Go не требуется.
Для открытия SPICE-консоли нужен отдельно установленный **Virt Viewer** (`remote-viewer.exe`).

## Подключение

Запустите `oVirtAutoConnect.exe` двойным щелчком. При первом запуске введите логин,
пароль и профиль oVirt. Имя ВМ вводить необязательно.

- Если имя ВМ задано через `-v` или сохранено в настройках, программа ищет эту ВМ.
- Если имя ВМ **не задано**, программа получает список доступных ВМ и подключается
  к первой (`vms[0]`) в порядке, в котором её вернул сервер oVirt — без сортировки.

Выбор первой ВМ автоматически **не сохраняется**: при следующем запуске сервер
может вернуть машины в другом порядке. Имя пользователя не подставляется в качестве имени ВМ.

Программа получает OAuth2-токен, находит ВМ, при необходимости запускает её и
открывает SPICE-консоль.

### Если виртуальная машина не найдена

Поиск не зависит от регистра (`Linux` и `linux` считаются одинаковыми).
Если явно указанная ВМ не найдена, программа получает список доступных ВМ
(до 1000) и предлагает выбрать одну по номеру. Выбранное имя сохраняется и
используется при следующих запусках.

Если список пуст, проверьте права пользователя в oVirt и корректность профиля.

## Команды

Откройте PowerShell в папке с EXE:

```powershell
.\oVirtAutoConnect.exe --list        # вывести доступные ВМ и их состояния
.\oVirtAutoConnect.exe --choose      # выбрать ВМ из списка и подключиться
.\oVirtAutoConnect.exe -v "Linux"    # сохранить указанную ВМ и подключиться
.\oVirtAutoConnect.exe --setup       # заново задать логин, пароль, профиль и необязательную ВМ
.\oVirtAutoConnect.exe --clear-vm    # сбросить имя ВМ, чтобы выбирать первую доступную
.\oVirtAutoConnect.exe --help        # полный список параметров
```

## Сохранённые настройки

Учётные данные и выбранное имя ВМ хранятся в Windows Credential Manager,
записи начинаются с `ovirt-auto-connect-windows/`.

**Обратите внимание:** при обновлении приложения ранее сохранённое имя ВМ
сохраняется. Если до обновления была задана `Linux`, программа продолжит
использовать `Linux`, пока вы не измените её через `--setup`, `-v` или `--choose`.
Чтобы использовать первую ВМ из ответа сервера, выполните `--clear-vm`.
При `--setup` можно оставить поле «Имя ВМ» пустым — сохранённое имя будет удалено.

## Исходники и тестирование

В `source/` находятся исходники Go (1.23+, только стандартная библиотека).
Сборка на Windows: `go build -trimpath -o ..\oVirtAutoConnect.exe .`.
Автоматические тесты: `go test ./...`.

Приложение кросс-скомпилировано для Windows x64. Проверены тесты формата
REST-запросов, XML, поиска ВМ, TLS и OAuth2 на тестовом HTTP-сервере.
Реальное подключение к корпоративному oVirt и запуск Virt Viewer на Windows
в этой среде не проверялись.

Никому не пересылайте пароль, содержимое `.vv` или `access_token`.
